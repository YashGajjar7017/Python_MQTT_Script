## Usage

### 1. Launch Interactive Menu
Run the application without arguments to open the numbered menu:

```powershell
python mqtt_app.py
```

```text
================================================================================
              MQTT REMOTE DEVICE CONTROLLER - MAIN SELECTION MENU
================================================================================

Please select a Configuration File or Action:

  [1] config.yaml                  (Default Medha Server YAML Config - 9 Topics)
  [2] config.xml                   (Medha Server XML Configuration)
  [3] custom_device_example.json   (Custom JSON Configuration)
  [4] Custom IMEI & Host Wizard    (Input custom IMEI & Host, save to JSON, then continue)
  [5] Offline Simulator Mode       (Test without connecting to live broker)
  [6] Exit

--------------------------------------------------------------------------------
Enter your choice (1-6): 
```

### 2. Run Directly with Configuration
```powershell
# Run with YAML config
python mqtt_app.py -c config.yaml

# Run with XML config
python mqtt_app.py -c config.xml

# Run with JSON config
python mqtt_app.py -c custom_device_example.json
```

### 3. Test in Offline Simulator Mode (No Network Needed)
```powershell
python mqtt_app.py --simulate
```

### 4. Run Self-Test Suite
```powershell
python test_handshake.py
```
